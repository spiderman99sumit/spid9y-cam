# Security reports

For a suspected vulnerability, use this repository's private vulnerability-reporting feature if available. Avoid posting a working exploit or private information in a public issue. For ordinary bugs, use the issue template.

The receiver accepts camera/control access only on loopback. Browser requests from external origins and cross-site requests to camera endpoints are rejected. ADB authorization is controlled by Android; the application does not enable USB debugging, approve a PC, or change installation security settings on the user's behalf.

Do not expose the local server through port forwarding, tunnels, reverse proxies, or public hosting. This beta is designed for a trusted local PC and an authorized USB-connected phone, not as an Internet camera service.
